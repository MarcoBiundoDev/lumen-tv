# Lumen TV

An IPTV player for Fire TV, Android TV, phones and tablets, with optional Emby support.

## Install on a Fire TV Stick

1. On the Fire TV, install **Downloader** from the Amazon app store.
2. Settings → My Fire TV → Developer options → **Install unknown apps** → turn on **Downloader**.
3. Open Downloader and type this address:

   ```
   github.com/MarcoBiundoDev/lumen-tv/releases/latest/download/LumenTV.apk
   ```

4. Press **Install** when it asks, then **Open**.
5. Sign in with your own IPTV server, username and password. Emby is optional (Emby Movies / Emby TV tabs).

The same address always gives the newest version: to update, just download it again.

## Android phone or tablet

Open the address above in a browser, open the downloaded file and allow installing from your browser when asked.
